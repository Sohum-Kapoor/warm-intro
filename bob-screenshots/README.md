# IBM Bob screenshots

The hackathon requires each team member's screenshots of IBM Bob usage in the repository. Capture them the way the Hackathon Guide describes (download it from the "Complete the hackathon" page on the challenge site).

- `sk/`: SK's screenshots. Piece built with Bob: `scripts/validate_data.py` (task S10).
- `jesse/`: Jesse's screenshots. Piece built with Bob: `tools/summarize_run.py` (task J3).

Take screenshots while you work, not afterwards. Check that no API key is visible in any image.
