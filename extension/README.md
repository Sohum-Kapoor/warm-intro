# Warm Intro: Chrome extension

Warm Intro: reimagining how Michigan connects. Your AI agent works in the background. This popup shows what it did this week: the agents it met, the introductions that got two yes votes, and the meetings it declined, with reasons.

Members are synthetic. Agent conversations, votes and introductions are AI-generated by IBM Granite.

## Load it unpacked

1. Open `chrome://extensions`.
2. Turn on **Developer mode** (top right).
3. Click **Load unpacked** and select this `extension/` folder.
4. Pin Warm Intro from the puzzle-piece menu. The badge shows how many new introductions the signed-in member has.

## Demo mode (default)

With no API set, everything comes from `data/site_data.js`, a bundled copy of the site's Granite run. MV3 forbids remote code, so nothing is loaded from a CDN.

- **Member switcher:** the 8 demo members. The default is Kestrel Stamping (m001). Priya N. (m003) shows the declined meeting: unpaid roles were her deal-breaker.
- **Say hello / Not now:** saved locally, and the badge updates. In demo mode nothing is sent.
- **Ask your agent:** keyword-matches the 4 precomputed asks. Anything else gets an honest answer: live mode runs it on IBM Granite.
- **Active/Paused:** stored locally.

To refresh the data after the site is regenerated:

```sh
python3 extension/sync_data.py    # copies site/data/site_data.js and checks it parses
python3 extension/make_icons.py   # only if you change the icon
```

Then click the reload icon on the extension's card in `chrome://extensions`.

## Live mode

Right-click the toolbar icon, choose **Options**, or click the **Demo** pill in the popup. Paste the API base URL (for example `https://xyz.trycloudflare.com`), then **Test connection** and **Save**. The popup calls:

| Call | Used for |
| --- | --- |
| `GET {api}/members/{id}/activity` | the weekly view and the badge |
| `POST {api}/ask` `{member_id, request, meet: true}` | Ask your agent |
| `PATCH {api}/members/{id}` `{paused}` | Active/Paused toggle |

The allowed hosts (`host_permissions`) are:
- `https://*.trycloudflare.com/*`
- `https://*.appdomain.cloud/*` (IBM Code Engine)
- `http://localhost/*`

If the API can't be reached, the popup falls back to demo data and says so. **Use demo data** clears the API URL.

## Files

| File | Role |
| --- | --- |
| `manifest.json` | MV3. The only permission is `storage`. |
| `popup.html`, `popup.css`, `popup.js` | The popup (380×560) |
| `lib.js` | Shared code: data adapter, storage, API calls, ask matching, badge. `demoActivity()` returns the same shape as the live activity endpoint. |
| `background.js` | Service worker. Sets the badge on install, at startup and when settings change. |
| `options.html`, `options.css`, `options.js` | The API URL setting |
| `preview.html`, `preview.js` | Shows the popup in a 380×560 frame for headless screenshots. Query params pass through: `?member=m003`, `&expand=1` (opens the first meeting), `&ask=machine vision`, `&api=http://localhost:8000`. |
| `sync_data.py`, `make_icons.py` | Refresh the data and redraw the icons (standard library only) |
